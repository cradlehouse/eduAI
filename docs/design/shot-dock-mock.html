Which one?
1Icon rail (unchanged). The organisation and cohort menu shrinks to icons when a project is open, and each icon names itself on hover.
2Project panel (as built today, plus one change). The film's steps sit under the open project: Script, Cast, Places, Props, Scenes, Crew. Each shows a count. New: a gold line saying what's still missing, and the film settings at the bottom.
3Takes grouped by prompt. Each row shows the prompt that made it, the engine, length, camera, when it ran, Again and delete. Instructors can read how the prompts changed from try to try.
4Actions on every still (shown on hover): Choose, Make video, Use for… (a character), Set as master wide (a place), Edit.
5Reference chips. The scene's cast and place are pinned already. Each chip sends that entry's look to the model.
6Type @ to pull in anyone from Cast, Places or Props. Picking one adds a chip. This replaces the separate picker.
7Start and end frames. The start frame defaults to the chosen still or the place's master wide. An end frame lets a shot land exactly on the next one.
8Camera motion as pictures, using the LTX presets. The last tile explains the options in plain words.
9One bar, one button. The engine is fixed for the film, so the only choice here is Fast or Quality. The button shows the price before you spend it (3 × 6 s at 9¢/s).
